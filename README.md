# CSS Animation Lab — Collection of Frontend Experiments

Repository eksperimen **CSS transition, transform, timing function, dan animasi elemen**. Walaupun nama repository memuat kata `PHP`, file yang ditinjau didominasi **HTML dan CSS**, bukan aplikasi backend PHP.

## Eksperimen di dalamnya

- `anima-property.html` dan `123/animation-property(3).html`: perubahan properti visual saat hover.
- `transition.html` dan `timing.html`: eksplorasi transisi dan pengaturan kecepatan animasi.
- `ROTATE.HTML`, `an1.html`, dan `an2.html`: latihan gerak serta transformasi.
- `loading.html`: elemen animasi loading.
- `slider-animation.html`, `scrolling.html`, dan `vertical-caraousel.html`: eksperimen interaksi/gerakan konten.

## Teknologi dan hasil

**HTML5 dan CSS3**, dengan berkas mandiri yang dapat dibuka untuk membandingkan efek animasi. Proyek ini berfungsi sebagai **laboratorium frontend dan referensi teknik visual**, bukan sistem portofolio full-stack.

Hasil utamanya adalah serangkaian contoh kecil yang membantu memahami perbedaan antara animasi berbasis `transform`, `transition`, dan pengaturan `timing-function`.
